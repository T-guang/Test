# 已知风险与禁改区

## 高风险边界

1. **`CircuitStateAnalyzer`** 是中心拓扑/状态解释器，仍承载大量电气知识，受 18 模板基线保护。没有专项方案和新证据前，不要拆分或调整其顺序。
2. **`SimulationEngine` 与 `RuntimeStateManager`** 通过可变的计时、保护、接触器和运动状态紧耦合。不要随意改重置或更新顺序。
3. **`WorkspaceController`** 涉及接线、选择、历史、仿真和保存加载。修改可能影响活动图和用户数据。
4. **`Demo.unity` 根层静态对象** 已做取证，尚未发现运行态污染。未单独立项前，不得删除或移动根层对象。
5. **检查流程顺序** 会通过报告 Block、状态文案、RuleId 和颜色被学习者看到。`InspectionWorkflowService` 特意保持了原有顺序。
6. **RuleId 与 Severity** 是契约。不得改名、降级，或从报告文字推断它们。
7. **基线是预期行为，不是修复工具。** 不得为了让失败验证通过而重生成 expected JSON。
